Default Keyboard Shortcuts

  • Ctrl + Mouse Wheel: zoom in/out
  • Ctrl Num(+) / Num(-): zoom in/out
  • Ctrl + 0: reset zoom
  • Ctrl + A / C / V / X / Y / Z
  • F3: Toggle cursor visibility (recover cursor)
  • F5: reload page
  • F6: Game Input Mode (forward keys to page/game)
  • F11: Toggle app fullscreen (hide/show browser chrome)
  • Video control: Space/Arrows (volume can be controlled outside TV)

Local Apps

  • App route formats: home:<app-id>, undernet:<app-id>, undernet:app/<app-id>
  • App location: UserData/UnderNetBrowser/root/Apps/<app-id>/index.html
  • Built-in example app: home:example (ensured by the mod when needed)
  • Fallback: if a requested app is missing, navigation falls back to the homepage

Reserved built-in route names (home, games, settings, notepad, ai, discord) are handled as built-in pages/features, not local app IDs.
