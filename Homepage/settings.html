Shortcuts

  • Ctrl + Mouse Wheel: zoom in/out (pointer over browser)
  • Ctrl + = / + / Numpad+: zoom in (fallback)
  • Ctrl + - / Numpad-: zoom out (fallback)
  • Ctrl + 0: reset zoom
  • Ctrl + A / C / X / V / Z and Ctrl + Y: edit shortcuts in web fields
  • F5: reload page (default, configurable)
  • Space: smart play/pause or space typing

Mod Configuration

Preferences are stored in MelonLoader config for this mod. Edit values there, then restart/reload as needed for changes that apply on startup.

Typical file: <Schedule I>/UserData/MelonPreferences.cfg
Category ID: FireskyUnderNetBrowser (display name: Firesky UnderNet Browser)
  • HomeUrl: undernet:home uses the built-in desktop homepage
  • Keybinds: cursor toggle, reload, game-input mode (see config entries)
  • Behavior/diagnostics: logging and browser behavior options (varies by version)

Local Content

  • Homepage: UserData/UnderNetBrowser/root/Homepage/index.html
  • Games page: UserData/UnderNetBrowser/root/Homepage/games.html
  • Settings page: UserData/UnderNetBrowser/root/Homepage/settings.html
  • Local apps: UserData/UnderNetBrowser/root/Apps/<app-id>/index.html → home:<app-id>

These files are user-editable. If missing, defaults may be regenerated by the mod.
